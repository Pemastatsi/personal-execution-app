Clarity, with character.

Three distinct visual systems for the same moment: knowing what to do next. Compare Focus and Roadmap in both themes. Every screen uses the same task, instructions and verified progress.

Theme
A

Precision Modern

Geometric. Decisive. Composed.

Focus / Light390 × 844

The structure. A sharp typographic scale, an inset action surface and a compact milestone ledger. Space Grotesk headings give the interface a precise, technical character.

Strongest at rapid scanning and making the primary action unmistakable. The current outcome has a decisive contrast change.

Tradeoff. The visual discipline can feel formal. Roadmap rows are denser and more utilitarian than the other directions.

B

Atmospheric Modern

Luminous. Layered. Reassuring.

Focus / Light390 × 844

The structure. An open, centered action stage, a floating instruction surface, rounded navigation and a five-stop outcome path. Layering gathers attention around one instruction.

Strongest at warmth, depth and an inviting sense of continuity. Light and dark feel related without simply inverting each other.

Tradeoff. More visual texture surrounds the action. The large surfaces need careful contrast control and may be less comfortable for texture-sensitive users.

C

Refined Minimalism

Editorial. Tactile. Deliberate.

Focus / Light390 × 844

The structure. A page rather than a stack of cards: Newsreader display typography, fine rules, chapter numbers and warm paper tones. The instruction leads; supporting context follows.

Strongest at calm reading and a distinctive, mature identity. Spacing and typography establish hierarchy with very little decoration.

Tradeoff. Serif instructions feel less technical and may scan more slowly. The subtler row affordances need usability testing.

All concepts open the same fictional project: Build a trading indicator. Two of five outcomes are verified; the current milestone is Compile the indicator without errors. The next action is always Open the editor and locate the error list.

All use the existing execution model: adjustable instruction detail, action completion with Undo, explicit outcome verification, AI help, task switching, evidence inspection and Focus / Milestone / Roadmap navigation. The other screens retain the original Astra design.
